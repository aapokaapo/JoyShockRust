# Feature compatibility matrix

Reference code reviewed 2026-11-22 at the revisions in the [Phase 0 reference analysis](docs/REFERENCE_ANALYSIS.md). **Source-confirmed** describes behavior visible in the inspected code. JoyShockRust statuses track implementation and test evidence separately. Physical behavior and feature parity require their own tests.

Descriptor, permissions and active-control captures remain pending.
